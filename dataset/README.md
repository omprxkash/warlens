# Dataset

500 labeled images (100 per class), organised by category:

- `Combat/`
- `DestroyedBuildings/`
- `Fire/`
- `Humanitarian Aid and rehabilitation/`
- `Military vehicles and weapons/`

Images were collected from publicly available news photography and open licensed sources for academic research on event classification in conflict zones, as part of the final-year project at VIT Chennai (see [../docs/paper/](../docs/paper/)).

If you intend to redistribute or use this dataset for commercial purposes, verify the licensing of each underlying source image yourself — the images are aggregated here under fair-use for non-commercial research only.
